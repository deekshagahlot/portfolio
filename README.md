# Deeksha Gahlot

Portfolio site for [Deeksha Gahlot](https://www.linkedin.com/in/deeksha-gahlot/), Senior UX / Product Designer.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Deploy

Connect this repo to [Vercel](https://vercel.com). Framework preset: **Vite**. Output directory: `dist`.

```bash
npm run build
```
